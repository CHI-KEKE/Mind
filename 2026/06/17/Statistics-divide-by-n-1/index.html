Why Dividing by N Underestimates Variance

Created2026-06-17|Updated2026-06-22|Statistics
|Post Views:

變異數在算什麼？它在算「資料點與平均值之間的距離平方的平均」。資料點離平均值越遠，變異數越大；離得越近，變異數越小

我們真正想知道的是全部資料圍繞在「母體平均數」周圍的變異程度。但現實中幾乎沒有足夠的時間與金錢去測量母體中的每一個個體，所以必須用抽樣資料來估計母體的變異數。

公式的兩個版本

理想上，真正的母體變異數是用母體平均數 μ\mu 計算的：

母體變異數 σ2=∑(x−μ)2N\sigma^2 = \dfrac{\sum (x - \mu)^2}{N}

但現實中我們只有樣本，只能算出樣本平均數 x‾\bar{x}，並用它代替 μ\mu：

為什麼分母要用 n−1？

課堂上會發現，母體變異數與樣本變異數在分母有所差異：

∑(x−x‾)2n\dfrac{\sum (x - \bar{x})^2}{n} ＜ ∑(x−x‾)2n−1\dfrac{\sum (x - \bar{x})^2}{n-1}

除以 n−1n-1 是在補償一個系統性偏差：我們計算的是「樣本點到 x‾\bar{x} 的距離」，而不是「樣本點到真正母體平均數 μ\mu 的距離」。由於 x‾\bar{x} 是這批樣本自己算出來的，它天生會偏向這批樣本，導致平方距離總和偏小。用 n−1n-1 可以把估計值拉回來

但「一定會偏小」嗎？偏小的原因是什麼？為什麼剛好是 n−1n-1？

這是最重要的一點！數學上可以證明：對於任何一組抽樣資料，「樣本平均數」剛好會讓所有資料點的距離平方和「最小」。換句話說，不管你拿什麼數字當中心點，用樣本平均數算出來的結果，永遠是所有選擇裡最小的

Step 1｜設定一個「未知的中心點 V」

先假裝不知道用誰當中心點算出來的距離最小，設定一個未知數值 VV。

我們的問題是：

VV 要是多少，才能讓 ∑(X−V)2n\dfrac{\sum(X - V)^2}{n} 的值最小？

Step 2｜畫出 U 型曲線，尋找「谷底」

把各種不同的 VV 值代入，把對應的變異數畫在圖表上，會形成一條 U 型曲線

例如

  • U 型曲線的最底端＝ 變異數最小的地方
  • 在數學裡，谷底的特徵是斜率為零（因為谷底是平的）

Step 3｜用微積分找「斜率為零」的點

現在我們的問題是當 VV 改變時，這整個值會怎麼變？這就是「對 VV 求導」

3-1｜把 1n\frac{1}{n} 提到外面

1n\frac{1}{n} 只是固定倍數，微分時可以先放外面： ddV[1n∑(X−V)2]=1n⋅ddV[∑(X−V)2]\frac{d}{dV}\left[\frac{1}{n}\sum(X-V)^2\right] = \frac{1}{n} \cdot \frac{d}{dV}\left[\sum(X-V)^2\right]

整包東西都除以 nn，微分結果也會除以 nn。

3-2｜對總和微分 → 拆成每項各自微分

∑(X−V)2\sum(X-V)^2 展開是： （x1−V)2+(x2−V)2+⋯+(xn−V)2（x_1-V)^2 + (x_2-V)^2 + \cdots + (x_n-V)^2

微分有個規則：一堆東西相加的微分 = 每一項各自微分後再相加

ddV[∑(X−V)2]=∑ddV(X−V)2\frac{d}{dV}\left[\sum(X-V)^2\right] = \sum \frac{d}{dV}(X-V)^2

3-3｜用 Chain Rule 微分 (X−V)2(X-V)^2

(X−V)2(X-V)^2 有兩層結構：

層 內容
外層 (⋅)2(\cdot)^2，某個東西的平方
內層 u=X−Vu = X - V

令 u=X−Vu = X - V，則原式為 u2u^2。Chain Rule 說 : ddVu2=dduu2⏟外層對 u 微分⋅dudV⏟內層對 V 微分\frac{d}{dV}\, u^2 = \underbrace{\frac{d}{du}\, u^2}_{\text{外層對 }u\text{ 微分}} \cdot \underbrace{\frac{du}{dV}}_{\text{內層對 }V\text{ 微分}}

外層微分： dduu2=2u=2(X−V)\frac{d}{du}\, u^2 = 2u = 2(X-V)

內層微分： XX 是固定的資料點，對 VV 來說是常數，所以 ddV(X−V)=−1\frac{d}{dV}(X - V) = -1

VV 增加 1，X−VX - V 就減少 1。

合併（Chain Rule 結果）： : ddV(X−V)2=2(X−V)⋅(−1)=−2(X−V)\frac{d}{dV}(X-V)^2 = 2(X-V) \cdot (-1) = -2(X-V)

這就是 Chain Rule 產生負號的地方。

3-4｜代回整個式子，整理斜率

ddV[1n∑(X−V)2]=1n⋅∑ddV(X−V)2=1n⋅∑[−2(X−V)]=−2n∑(X−V)\frac{d}{dV}\left[\frac{1}{n}\sum(X-V)^2\right] = \frac{1}{n} \cdot \sum\frac{d}{dV}(X-V)^2 = \frac{1}{n} \cdot \sum\left[-2(X-V)\right] = \frac{-2}{n}\sum(X-V)

3-5｜令斜率為零，找谷底

斜率公式：ddV[1n∑(X−V)2]=−2n∑(X−V)\dfrac{d}{dV}\left[\frac{1}{n}\sum(X-V)^2\right] = \dfrac{-2}{n}\sum(X-V)

令斜率等於零：−2n∑(X−V)=0\dfrac{-2}{n}\sum(X-V) = 0

兩邊乘以 n−2\dfrac{n}{-2} 消去係數：∑(X−V)=0\quad \sum(X-V) = 0

白話：把每個資料點 XX 減去 VV 之後全部加起來，等於 0。

Step 4｜解出 V

展開 ∑(X−V)=0\sum(X - V) = 0 : ∑X−nV=0\sum X - nV = 0

移項解出 VV：V=∑Xn\quad V = \dfrac{\sum X}{n}

🎯 結論

「所有資料點的總和除以資料總數 nn」——這完全就是樣本平均數 X‾\bar{X} 的計算公式！

數學直接證明了：不管你有多少筆資料，只要你想找讓「距離平方和最小」的中心點，答案永遠都是樣本平均數 X‾\bar{X}。

關鍵前提

從上一個 tab 我們知道：用 x‾\bar{x} 算出的變異數，是所有可能的中心點中最小的。

而抽樣出來的 x‾\bar{x}，幾乎不可能剛好等於真正的母體平均數 μ\mu。

推論

情境 使用的中心點 算出的變異數
理想（不可得） 母體平均數 μ\mu 較大（真實值）
現實（我們只有這個） 樣本平均數 x‾\bar{x} 較小（最小值）

由於 x‾\bar{x} 算出的距離平方和天生偏小，直接除以 nn 得到的變異數，會比真正的母體變異數還要低估。

用樣本平均數 x‾\bar{x} 取代母體平均數 μ\mu 計算變異數，會造成系統性低估

因此，直接把總和除以 nn，算出來的數字會比實際的母體變異數小——這就是所謂的「低估（underestimation）」

Step 1｜拆解每筆資料的偏差

對每一筆資料 xix_i，它和真正母體平均 μ\mu 的距離可以拆成兩段：

xi−μ=(xi−x‾)⏟資料到樣本平均+(x‾−μ)⏟樣本平均到母體平均x_i - \mu = \underbrace{(x_i - \bar{x})}_{\text{資料到樣本平均}} + \underbrace{(\bar{x} - \mu)}_{\text{樣本平均到母體平均}}

Step 2｜兩邊平方，展開

用 (a+b)2=a2+2ab+b2(a+b)^2 = a^2 + 2ab + b^2：(xi−μ)2=(xi−x‾)2+2(xi−x‾)(x‾−μ)+(x‾−μ)2(x_i - \mu)^2 = (x_i-\bar{x})^2 + 2(x_i-\bar{x})(\bar{x}-\mu) + (\bar{x}-\mu)^2

Step 3｜對所有資料加總

∑(xi−μ)2=∑(xi−x‾)2+2(x‾−μ)∑(xi−x‾)+n(x‾−μ)2\sum(x_i-\mu)^2 = \sum(x_i-\bar{x})^2 + 2(\bar{x}-\mu)\sum(x_i-\bar{x}) + n(\bar{x}-\mu)^2

中間那項消失： ∑(xi−x‾)=0\sum(x_i-\bar{x}) = 0

所有資料減去自己的平均數，偏差總和恆等於 0。

所以化簡為： ∑(xi−μ)2=∑(xi−x‾)2+n(x‾−μ)2\sum(x_i-\mu)^2 = \sum(x_i-\bar{x})^2 + n(\bar{x}-\mu)^2

Step 4｜移項，看少掉多少

∑(xi−x‾)2=∑(xi−μ)2−n(x‾−μ)2\sum(x_i-\bar{x})^2 = \sum(x_i-\mu)^2 - n(\bar{x}-\mu)^2

用 x‾\bar{x} 算出來的平方距離總和，比用 μ\mu 算少掉了 n(x‾−μ)2n(\bar{x}-\mu)^2。

Step 5｜取期望值，計算「平均少多少」

左側（用 μ\mu 計算的完整平方距離）：

每一筆資料平均貢獻一份 σ2\sigma^2，nn 筆合計： E[∑(xi−μ)2]=nσ2E\left[\sum(x_i-\mu)^2\right] = n\sigma^2

少掉的那塊（x‾\bar{x} 偏離 μ\mu 的誤差）：

樣本平均 x‾\bar{x} 本身的變異數是 σ2n\dfrac{\sigma^2}{n}，所以： E[n(x‾−μ)2]=n⋅σ2n=σ2E\left[n(\bar{x}-\mu)^2\right] = n \cdot \frac{\sigma^2}{n} = \sigma^2

Step 6｜得出結論

E[∑(xi−x‾)2]=nσ2−σ2=(n−1)σ2E\left[\sum(x_i-\bar{x})^2\right] = n\sigma^2 - \sigma^2 = (n-1)\sigma^2

情境 平方距離總和的期望值
用真正 μ\mu 計算 nσ2n\sigma^2
用樣本 x‾\bar{x} 計算 (n−1)σ2(n-1)\sigma^2（少掉一份）

因此，要從 ∑(xi−x‾)2\sum(x_i-\bar{x})^2 還原回 σ2\sigma^2，必須除以 (n−1)(n-1)：

s2=∑(xi−x‾)2n−1\boxed{s^2 = \frac{\sum(x_i-\bar{x})^2}{n-1}}
