Fixed Point & Floating Point

Created2026-08-26|Updated2026-08-30|CS
|Post Views:
CS · NUMBER REPRESENTATION

小數點放在哪裡，決定數值能表示什麼

電腦只有有限的 bits，卻要表示從很小到很大的數字。理解二進位小數、fixed point 與 floating point，就能看懂精度、範圍與誤差從哪裡產生。

Binary FractionFixed PointFloating Point
01

二進位小數如何表示

十進位小數的小數點後，每一格都有固定權重。第一格是 1/10，第二格是 1/100，第三格是 1/1000。

0.123 = 1 × 1/10 + 2 × 1/100 + 3 × 1/1000

二進位小數的規則完全相同，只是底數從 10 改成 2。因此小數點後第一格代表 1/2，第二格代表 1/4，第三格代表 1/8。

0.101₂ = 1 × 1/2 + 0 × 1/4 + 1 × 1/8 = 0.625₁₀

💡

核心觀念：二進位小數就是用一連串的 1/2ⁿ 湊出目標數值。

02

十進位的 0.1，為什麼會變成循環小數

把十進位的 0.1 轉成二進位，本質上是在反覆檢查每個 1/2ⁿ 是否能放進剩餘值。

1
檢查 1/2 = 0.5

0.1 < 0.5，第一格放不下，所以是 0。

2
檢查 1/4 = 0.25 與 1/8 = 0.125

兩者都比剩餘值大，所以第二格與第三格都是 0。

3
檢查 1/16 = 0.0625

0.1 ≥ 0.0625，第四格可以放入 1，剩下 0.0375。

4
繼續用後面的權重湊出剩餘值

第五格放入 1/32，第六格與第七格放入 0，第八格再放入 1/256。結果逐步形成 0.0001100110011…。

⚠️

為什麼會循環：0.1 = 1/10 = 1/(2 × 5)。有限長度的二進位小數，其最簡分數的分母只能包含質因數 2。因數 5 無法被有限個二次方消除，因此 0.1 只能用無限循環的小數逼近。

十進位數值 二進位表示 原因
0.75 0.11₂ 0.75 = 1/2 + 1/4，可以有限表示。
0.625 0.101₂ 0.625 = 1/2 + 1/8，可以有限表示。
0.1 0.000110011…₂ 最簡分數分母含有因數 5，只能循環。
03

Fixed point：小數點位置固定

Fixed point 的做法是先約定小數點永遠放在固定位置。例如使用 xxxx.xxxx，前 4 個 bits 表示整數，後 4 個 bits 表示小數。

0011.1000₂ = 0 × 8 + 0 × 4 + 1 × 2 + 1 × 1 + 1 × 1/2 = 3.5

固定精度

小數點後有幾格，最小單位就固定。例如 4 個小數 bits 的最小單位是 1/16。

範圍受限

若只有 4 個 bits 表示整數，最大值是 15。增加小數精度，就會減少整數範圍。

適合固定尺度

金額、尺寸、感測值等需要固定小數位的資料，通常容易使用 fixed point 管理。

📌

取捨關係：bits 總數固定時，分給整數的 bits 越多，能表示的範圍越大。分給小數的 bits 越多，精度越高。

04

Floating point：讓小數點可以移動

Floating point 不固定小數點位置，而是把數值拆成有效數字與指數。概念上就像科學記號。

123000000 = 1.23 × 10⁸

0.000000123 = 1.23 × 10⁻⁷

兩個數值的有效數字都是 1.23，差異主要由指數決定。二進位 floating point 則使用類似 1.xxxx₂ × 2ⁿ 的形式。

欄位 用途
sign 表示正數或負數。
exponent 決定二進位小數點要移動的數量級。
fraction 保存有效數字的精細程度。

Fixed point

小數點固定，精度與最小單位穩定，數值範圍比較容易不足。

Floating point

小數點可以浮動，能涵蓋很大的數值範圍，但不同數量級的精度不相同。

實際差異

Floating point 的相鄰可表示數字之間，距離會隨數值大小改變。

✓

總結：Floating point 的價值不只是表示小數，而是用有限 bits 同時涵蓋極小到極大的數值範圍。若需求是固定最小單位，fixed point 通常更容易控制。

  • 二進位小數的每一格，代表一個 1/2ⁿ。
  • 最簡分數的分母只含因數 2，才能用有限長度的二進位小數表示。
  • Fixed point 以固定小數點換取穩定精度。
  • Floating point 以有效數字加指數換取更大的數值範圍。
